# Commit convention - Rug Rush

Format: `<type>: <imperative summary> v<MAJOR.MINOR.PATCH>`

- Types: `feat`, `fix`, `chore`, `docs`, `refactor`, `test`.
- The version number always closes the title, matching `package.json`.
- Example: `feat: initial game loop, renderer, and cozy UI v0.2.0`

Bodies are detailed: what changed, why, and the old -> new version with the
reason for the bump level.

Commits are authored by Roni Amiel & Noa Amiel. No AI or tool co-author
trailers.
